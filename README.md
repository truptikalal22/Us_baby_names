# US Baby Names Analysis

## About the Project

Choosing a baby's name has always been influenced by culture, trends, and time. In this project, I explored the US Baby Names dataset to understand how naming patterns have changed over the years.

Using Python, I cleaned the dataset, analyzed the data, and created visualizations to discover interesting trends, such as the most popular names, gender-based differences, and how the popularity of names has evolved.

## Dataset

The dataset contains information about baby names registered in the United States, including:

- Baby Name
- Gender
- Number of Occurrences
- Year

## Running the Project

1. Clone this repository.

```bash

```

2. Go to the project folder.

```bash
cd Us_baby_names
```

3. Install the required libraries.

```bash
pip install -r requirements.txt
```

4. Open the Jupyter Notebook and run all the cells.
