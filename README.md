In this project, I worked on the U.S. Baby Names Dataset to understand baby naming trends and patterns over the years. I used Python libraries like Pandas and NumPy to clean and prepare the data by removing missing values, checking duplicates, and organizing the dataset properly.
After cleaning the data, I created an interactive dashboard in Power BI to show insights such as popular baby names, gender distribution, and yearly trends in an easy-to-understand way.
This project helped me improve my skills in:

Data Cleaning
Data Analysis
Data Visualization
Dashboard Creation
Working with real-world datasets
